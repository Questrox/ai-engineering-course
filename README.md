# ai-engineering-course
## Troubleshooting

### 'Ошибка 400: Can't decode 'Authorization' header"`
**Что видел:** ошибка при запуске после того, как заменил ключ на набор случайных латинских букв.
**Почему:** ключ не является валидным, сервер не может его распарсить.
**Что сделал:** вернул настоящий ключ.

### 'Ошибка 401: clientId is absent in db"`
**Что видел:** ошибка при запуске после того, как заменил 1 букву в ключе.
**Почему:** ключ неверен.
**Что сделал:** вернул настоящий ключ.

### '[Errno 11001] getaddrinfo failed. Оба провайдера недоступны: Connection error.`
**Что видел:** ошибка при запуске скрипта.
**Почему:** отсутствует подключение к интернету.
**Что сделал:** вернул подключение к интернету.
